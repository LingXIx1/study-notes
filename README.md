# study-notes

自学编程的练习记录。

从零开始，每天写一点。这里放课上的练习题和自己踩过的坑，代码都很简单，但都是自己一行行敲出来的。

## 目录

- `practice/basics.py` — Python 基础语法（函数、类型转换）
- `practice/fib.py` — 递归与循环的对比
- `practice/guess_number.py` — 猜数字小游戏（while + 输入处理）
- `practice/score_stats.py` — 成绩统计（字典、排序、statistics）
- `practice/string_tools.py` — 回文判断与词频统计
- `practice/sort_demo.py` — 冒泡排序和内置排序对比

## 运行

```bash
python3 practice/score_stats.py
```

- Python 基础
- Git / GitHub 基本操作
- 数据结构入门（排序、递归）
